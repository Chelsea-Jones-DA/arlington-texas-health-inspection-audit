# Arlington Health Inspection Data Audit & Evolution

## The Backstory
I spent over a decade running food safety, quality assurance, and operational compliance. My day-to-day job was centered around finding operational breakdowns, catching human error, and enforcing strict standards. 

To bridge my background into digital tools, I took on volunteer IT support responsibilities—helping organize metric tracking, setting up operational workflows, and managing system tools.

## The Spark: My First Data Visualization
I wanted to see if my instinct for quality control would translate into data analytics. 

I grabbed a raw public dataset containing over 3,800 municipal health inspection records from Arlington, Texas. Following step-by-step guidance from Gemini, I built my very first geographic visualization on Tableau Public. 

* **First Viz Milestone:** [View My Original Arlington Health Inspection Map](tinyurl.com/Chelsea-Tableau) 

That project proved I loved the work, but it was just the beginning.

## The Training: Leveling Up
I went all-in on building a formal analytics stack. I took coursework and completed practical projects focused on:
* **Power BI & Power Query:** Data transformation, cell-by-cell data hygiene, record filtering, column standardization, and automated data cleaning routines.
* **Advanced Excel & SQL:** Formula logic, error tracing, database structures, and structured data filtering.
* **Tableau Public:** Visual data auditing and interactive dashboard design.

## The Proof: Cleaning the Arlington Dataset
To show my growth, I went back to the exact same Arlington health inspection file that started my journey. 

Instead of just mapping the numbers as they were, I used Power BI to execute a full audit and data sanitation process across all 3,800+ rows:
1. **Audited the Raw Data:** Identified input errors, text typos in facility names, inconsistent date formats, blank score entries, and misaligned record values.
2. **Sanitized in Power BI:** Cleaned dirty inputs, standardized facility classifications, stripped hidden text characters, and established repeatable transformation steps to fix the underlying data logic.
3. **Documented the Audit:** Created a detailed Notepad audit log detailing every single error identified and the exact cleaning steps taken.
4. **Interactive Exception Visualization:** *Building now — follow updates on my [Tableau Public Profile](tinyurl.com/Chelsea-Tableau)*
